# Изображения

`public/illustrations/{paper,notebook,pens,school}.svg` и `public/favicon.svg` — оригинальные векторные иллюстрации, созданные специально для этого проекта с помощью AI-инструментов. Автор проекта — Максим Асатуров. Фотографии, чужие товарные изображения, торговые марки или внешние ссылки внутри SVG не используются. Изображения условные: они обозначают категории, а не внешний вид реального товара.

Все 16 прежних ссылок `images.unsplash.com` заменены на локальные SVG. Соответствие прежних фотографий лицензии и конкретному фотографу не утверждается; повторно они не распространяются. Изображения загружаются с того же origin и учитывают GitHub Pages base `/market/`.

Лицензия кода проекта не изменялась; отдельное разрешение на стороннее переиспользование этих иллюстраций не предоставляется. Иконки интерфейса поставляются установленным `lucide-react` и сохраняют [его лицензию ISC](https://lucide.dev/license). Остальные библиотеки сохраняют собственные лицензии в зависимостях.
